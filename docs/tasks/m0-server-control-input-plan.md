## Closed interfaces and implementation

`TerminalCommandService` composes one authenticated connection's `TerminalSubscriptions` with an explicitly shared `ControlArbiter` for its exact `LocalRuntime`/`RuntimeComposition`; competing arbiters for that runtime are refused. B1 commands retain their existing path and ResultHandoff. The only B1 amendment admits focus/blur/resize/appearance/input into its original identity, reservation and route FIFO, and notifies the arbiter when an owned route retires. `ControlRouteContext` binds the complete subscription/worker and internal request/release IDs, with live-attempt and installed/applied-boundary predicates. `ControlJob` is admitted into run accepted order synchronously, becomes ready only at its B1 FIFO turn, and is cancelled without executing when that route retires. It never waits for an ACK behind itself: uninstalled/under-boundary commands refuse admission/execution.

The arbiter owns finite per-run confirmed holder/epoch/grid/atSeq, run FIFO jobs, monotonic focus/input counters scoped to the complete subscription and deferred conditional retirement release. Unknown control fences the run until a fresh existing status request confirms the boundary. Initial boundary uses an actual correlated existing status request, never the registry's unverified reservation. Accepted set-control results need only atSeq: admitted expected/next epoch and holder establish commitment. Every await and carrier/supplier reentrancy is followed by live identity/attempt and current ownership checks. A committed focus on a closed route gets no external grant; retirement cleanup runs after already accepted jobs and releases only that exact still-current holder and epoch. A watcher never releases or becomes elected. Release preserves geometry and expectedEpoch == nextEpoch. No PTY stop is emitted.

Input receives the binary payload explicitly; it has one worker request and no replay. Full backing is retained before copying and ownership, and the copy has its own reservation. Exact written prefix is reported; uncertain handoff is RESULT_UNKNOWN/unknown/input/inspect-run. Counter proof survives recover and remains finite until route retirement and all owned jobs/cleanup complete. Resize/appearance/input require the current exact holder/epoch, an actually accepted own grant and its applied boundary. Exact own blur requires an installed recovery boundary and releases without waiting for the grant fact to finish parsing. Dispatched input survives close settlement until its actual receipt/uncertainty; closed routes publish no late successful result. Retirement records bind the specific release epoch as well as the full holder. Ordered worker control/resize facts may advance the confirmed boundary but cannot replace a successful admitted own focus as grant proof.
