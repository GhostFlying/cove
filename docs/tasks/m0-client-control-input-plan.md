## Public and private boundary

Implement `TerminalController.setInputTarget(foreground, focused)`, `requestFocus(geometry?)`, `blur()`, `sendInput({ source, bytes })`, `requestResize(geometry)`, and `updateAppearance(appearance)`. `setInputTarget` returns a typed local outcome and changes host policy; explicit host `requestFocus` and qualifying `TerminalView.onFocusIntent` use the same focus admission path. `requestFocus`/blur/resize/appearance return a typed control outcome carrying matched epoch/atSeq on success. Input returns a bounded typed outcome with a local monotonically increasing input ID after valid admission, `writtenBytes`, `unknownBytes`, `notSentBytes`, and the original typed error on failure. A short written result credits only its exact prefix and classifies the rest of that handed-off chunk as unknown. No result claims that a shell or agent executed bytes. Snapshot additions are immutable control/readiness and bounded count fields; never reveal input bytes.

The lane owns wire focusSeq per connection/view and inputSeq per complete subscription. Neither resets on same-ref recovery or view replacement; exhaustion returns `COUNTER_EXHAUSTED`. The controller owns local focus-intent identity, view generation, explicit foreground/target desire, grant/result, latest validated control epoch/holder, applied control fact, and input-intent ID. A V1 focus callback is accepted only for its captured view/generation and strictly newer local focusSeq; an identical duplicate is ignored and a conflicting duplicate or older sequence cannot replace intent. Output, measurement, visibility, selection and ordinary recover never generate focus. Foreground reconnect may use retained host desire for one new focus only after a fresh attach/recover commit; background reconnect does not. `replaceView` clears inherited target and requires a new host/real view intent.

Input-ready requires one current binding and full ref, ready model, host foreground and target, a focus result for the latest local intent, `appliedSeq >= grant.atSeq`, and the latest _applied_ ordered control holder/epoch matching that ref/grant. A validated higher epoch or foreign/null holder revokes old input permission immediately on receipt, even before a slow renderer applies it. Positive permission waits for renderer completion and the focus-result boundary. Baseline has no authority field: baseline completion, recovery and appearance/resize results cannot reconstruct a missing grant or trigger a focus loop. Current epoch/ref/intent is checked again at actual socket handoff after any queued wait or synchronous callback. Blur and target loss revoke before attempting a bounded own-epoch command; late results cannot restore older permission.

Input copies genuine `Uint8Array` bytes, keeps source as local provenance, and never filters escape-like content. One intent over negotiated `inputQueueBytes` fails before any send; accepted intents split at protocol payload/frame limits without transcoding or merging. Staging is permitted only during the current explicit focus acquisition on an already-ready model and is bound to that focus token; no baseline/replay/offline staging. Pending/staged/in-flight input payload and frame copies each have an explicit bounded owner; retained byte count never exceeds the negotiated input budget for controller-owned intent payload, while encoded pending frames are separately charged to the existing connection outbound ledger. At most 224 input pending commands coexist in the lane's 256-command cap, leaving 32 local slots for ACK/progress/control/detach. A bounded per-ref send queue preserves that ref's order and uses a simple round-robin turn across refs; no second unbounded adapter queue. Unsent stale focus/input is cancelled only for its captured ref/intent; handed-off or uncertain bytes are never retried or moved to a new focus. One input intent stops its remaining chunks on short/overreported written result, rejection, unknown, target/epoch loss or disconnect.

Resize and appearance requests require a current applied grant and carry its epoch. Their result atSeq is only a correlated receipt; the view changes solely after an ordered server event is applied. A `requiresBaseline` resize still takes P3b same-ref non-resume recovery without ACKing that bad event and drops queued/staged input. A regular slow output parse does not suppress a ready keyboard/paste/mouse intent. Exit and all detach/recover/connection-loss/dispose/replace boundaries revoke input immediately, cancel only unsent current control/input and settle owned promises once while retaining physical parse/transport debt until actual release.
