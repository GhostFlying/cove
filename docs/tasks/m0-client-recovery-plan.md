## State and correctness invariants

One complete `SubscriptionRef` (run, `ConnectionRef`, subscriptionId, viewId) is the external route key. New attach/view/connection obtains a new identity; recovery of a live subscription preserves it. No second streamId or wire generation is added. Client owns the single binary decoder, one ordered send path, correlation and aggregate budgets. Each controller owns its local connection/recovery/view tokens, one route cursor, retained-model validity and a single parse drain. Every callback, timer and promise checks its captured tokens after each await. A view failure listener is bound to its generation before `initialize`, so synchronous failure is observed; advisory `INPUT_REJECTED` leaves the model valid, fatal renderer/recovery failures do not.

Validate exactly one complete protocol frame per WS binary callback, including full consumed length and bounded/fatal metadata decoding. Reject pre-bootstrap binary and post-bootstrap unexpected text. Route only a fully validated external event whose outer/inner run and complete active subscription match the current connection; unwrap the existing terminal event for `TerminalView`. Per-route parsing must not block a healthy different route.

For a baseline, validate descriptor/ref/profile/encoding/coverage/source geometry/atSeq and negotiated bounds. Invalidate old view operations, initialize the next generation at source geometry, begin baseline, parse chunks in exact ordinal order with one write in flight, and send parsed progress only after that chunk resolves. Check byte/chunk totals and end, await finish, commit applied sequence N, then hand off applied ACK N. Retained replay is allowed only for a matching profile/geometry/known parsed model with no uncertain parse; require offer/response consistency and exact `appliedSeq+1..atSeq`. Empty replay commits directly. Ordered live output/control/appearance/exit then advances the same cursor; gap, rollback, duplicate or `requiresBaseline` resize does not apply/ACK the bad sequence and schedules at most one non-resume recovery.

Local recovery starts by fencing old delivery and unsent ACK/progress before sending the command. Already handed-off bytes precede recover on the ordered uplink. The correlated recover result is the downlink marker: drop pre-marker data without ACK; post-marker data enters the new attempt. A legal same-ref/seq stale post-marker frame is not always distinguishable by the consumer; W2/P2 must prove producer retirement and ordered publication separately. Fake P3b tests will not claim that producer barrier.

Synchronous adapter callbacks may reenter send, settlement, disposal or listeners. Register correlation/route/timer before calling `send`; once entered, missing handle/result is unknown rather than definitely not sent. No attach/recover/input auto retry. Lost attach ref or unisolatable transport uncertainty retires the connection; known-ref local view failure can retire only that controller. A recover timeout/unknown outcome retires the ref; explicit subsequent attach uses a new ref. Detach fences locally before bounded best-effort remote notice. Dispose immediately invalidates and is idempotent; old unresolved parse may settle only its original call, never revive or ACK a replacement. Connection loss is `unverifiable`, not evidence of run exit.

Resource accounting reserves before copying: per-route queued plus active parse bytes <= effective subscription credit, items <= post-N limit; connection aggregate <= outbound bytes plus reserved control. Keep old physically retained parse bytes charged until actual settlement. Terminal pending commands <=256, controller slots <= effective subscriptions (at most 16), retired refs <=256 per connection, checked request/generation counters never wrap; cap exhaustion returns a typed local/domain failure rather than silently dropping or reusing identity. Per route ACK/progress are coalesced to at most one in flight plus one pending parsed boundary, without crossing attempts; 32 small control positions remain reserved. Adapter admission must be bounded and immediate, with no hidden unbounded queue. Recovery has one total negotiated deadline <=15s, not a renewed per-chunk timeout.
