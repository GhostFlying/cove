## Blocking counterexamples and bounded controls

**Retained alternate column, same-grid edit.** At 41×2 with no scrollback, enter alternate (`CSI ?47h`), print `B`×40 then `A`, reset pen, and resize the authoritative model to 40×2. The pinned alternate line retains physical length 41 and `A` at x=40. The current-width fresh receiver has length 40. Suffix `CUP 1;1` + `DCH 1` shifts the source `A` into visible x=39, while the receiver has an empty cell. The diagnostic asserts this mismatch in `recovery-boundaries.test.mjs`; its green result is a negative control. This is not merely a later-resize discrepancy. Pinned `BufferLine.deleteCells` edits to physical `line.length`, while non-reflowing alternate resize retains off-grid storage.

Receiver-only VT at width 41 then public resize to 40 preserves that minimal retained cell without changing source or PTY geometry. Current-width source VT also reconstructs one retained edge wide+combining glyph and an RGB styled blank when the receiver first runs at physical width 41. In that authored case the full public state and two DCH suffixes match. These are bounded positive controls, not a generic restoration recipe.

**Mixed physical row capacities.** A new alternate row allocated after 41→40 has length 40 while older rows remain length 41. Padding every row to 41 is wrong: ICH at the right edge followed by DCH can return a character on a padded row that the real 40-cell row discarded. A narrow public VT `DL`+`IL` replacement of the short row, tested with the short row first and last, recreated the authored 40/41 capacities and matched its ICH/DCH continuation. This proves a row-local operation can work in those two arrangements; it does not prove arbitrary row topology, style/wrap registers or both buffers.

**Hidden normal history.** With 41×3, history budget 3, `H`×200 followed by CRLF, `中é😀`, a saved red cursor, alternate entry and resize to 40, stock current-width VT loses `isWrapped=true` on the first retained normal row. Prepending one disposable 40-column dummy row before replay makes that leading wrap flag and the exact six retained normal rows match; after leaving alternate and `ESC8 X`, the complete public state matches. The dummy is evicted. While alternate is still active, the source's physical 41-column alternate lines still differ from this standalone receiver's 40-column lines; the later G result below addresses that authored combined fixture. The accepted architecture permits authoritative fresh baseline after incomplete reflow context, but does not waive same-grid continuation effects or silently ignore the flag.

**Ordinary printable checkpoint refresh, original failure and J result.** A safe checkpoint before output, followed by 65,537 plain `A` bytes, exceeds the 65,536-byte tail. Live parsing continues, but the pinned parser has `precedingJoinState=2` after the final printable. The original `createRecoveryCheckpoint` rejects that ground-state snapshot; this negative control remains in the suite. The J experiment builds the receiver's cell preimage from current VT, restores registers first, then reprints an authored, bounded final witness as the baseline's last bytes. It never writes the join scalar into the receiver. The candidate restores fresh models at five checkpoint offsets while streaming 131,073 `A` bytes in each of normal/alternate and 12/40-column cases: 20 actual checkpoint replacements. Measured peak tail is 32,784 bytes and peak baseline 711 bytes, both below the 64 KiB/8 MiB caps. Each generated baseline is independently parsed and compared before the tail is reset. Eight interior/pending-wrap, wide/combined, DEC, insert, wrap-disabled wide-overflow and bottom-margin cases pass four immediate suffixes each (printable, combining, REP and saved-cursor restore). Two multibyte cuts reject incomplete boundaries and succeed after completion. Source public/private observations are unchanged by generation, and pinned receiver join state matches source before each suffix.

This is a bounded positive candidate, not a universal refresh proof. The 64-byte witness guard rejects an authored 67-byte combined cluster; a future strategy must either account for that cluster inside the baseline bound or prove a smaller witness sufficient. The current J fixture supplies the original final bytes and preimage location explicitly; it has not proved an online tracker can derive them from all source streams, especially after resize or style/charset transitions. The diagnostic for the old ground-only strategy remains an expected mismatch, not R5 acceptance. One J/G composition fixture passes below; independent verification and broader source-driven generation remain open.

## G combined geometry result

The single initial combined schedule replayed source-generated current-40 VT into a temporary 41-column receiver, resized it to 40 and used row-local `DL`+`IL`. In the 4-row mixed fixture, the source's normal row 1 cell x=23 was `N` while the receiver's was blank; with the short alternate row first, source alternate row 3 x=40 contained a styled blank while the receiver's cell was empty. In the 3-line-history fixture, source normal retained line 0 had `isWrapped=true` while the receiver's was false. These are asserted expected mismatches, not passing restoration outcomes.

One evidence-driven correction inserts the missing `N` into the normal preimage at temporary width, writes the retained styled blank when that row survives, restores the off-grid tab stop at x=40 in each buffer, and adds one disposable 41-column normal row only when the leading retained history is wrapped. It then resizes the receiver once to authoritative width 40 and replaces the authored short alternate row with `DL`+`IL`. In both mixed-row orders (short row first and last), complete public observations and guarded private registers match, including saved red DEC cursor/charset, off-grid tabs, retained edge content and exact line capacities. Same-grid ICH/DCH, alternate exit, saved-cursor print, and subsequent normal state match. With history budget 3, the same corrected schedule has exactly six retained normal lines and no dummy residue; 40→41→40, a same-size resize, and the same edit/exit suffixes also match. A separate composition keeps the J final `Q` print as the last installation bytes after G's geometry steps; private join state and immediate combining and REP continuations match.

The G suite's measured maximum is 566 encoded installation bytes, 369 public receiver cells at temporary width, three geometry operations (one receiver resize, one DL, one IL), 41 temporary columns, four rows and one disposable row. The probe's owned VT byte array, decoded UTF-16 string and largest re-encoded write have a conservative combined peak budget of 1,654 bytes; this excludes the pinned serializer's internal allocations and is not a general algorithm bound. All geometry operations are receiver-only; source public/private snapshots and live reply count remain unchanged during generation.

The correction is deliberately authored for these fixtures. In particular, the missing normal `N`, its preimage coordinate, the styled blank's pen and the off-grid tab are supplied or inspected with fixture knowledge; the probe does not derive a general inverse of resize/reflow from arbitrary public source state. G proves that these combined states have a bounded public VT representation under the tested schedule. It does not yet establish a production snapshot generator, online J witness tracker, or cross-client restore protocol. The original R6 DCH counterexample remains a required negative control for current-width-only VT.

## Patch/API decision surface

No source patch, pin drift, production protocol or generic serializer was introduced. The bounded public controls show neither an impossibility proof nor a complete solution. A preservation patch, if required, would need an exact read-only export of retained per-line extents and unavailable saved/current attributes, and possibly an installation-only receiver action that can set per-line storage capacity and wrapped status without resizing/reflowing the other buffer. A serializer traversal change alone cannot install off-grid cells at fixed width 40. Relevant pinned surfaces are `Buffer.ts` resize/reflow, `BufferLine.ts` edit/cell capacity, `BufferSet.ts` both-buffer resize and alternate clearing, `InputHandler.ts` ICH/DCH, and addon-serialize row traversal. Any receiver action must preserve source/PTY size and live edit semantics and finish atomically before tail/suffix parsing.

That route would maintain a patch against both pinned headless and browser implementations, regenerated distributions, version/hash guards, upgrade conformance fixtures and Q1 reply-suppression parity. Changing live resize to discard hidden columns is a separate behavioral decision; it would change the authoritative model's DCH/widen behavior and mixed-client compatibility. The coordinator owns that user-facing tradeoff. Until J's witness strategy and combined geometry restoration are independently qualified, T1 does not meet its required R5/R6 acceptance even though its diagnostic tests and local CI checks pass.
