# P3e public terminal state — source contract and author checks

The controller snapshot exposes an immutable full `run`, `execution`, `appliedGeometry`, and `appliedAuthority`. `execution` is evidence about that run: an admitted ordered exit or a validated caller-initiated `terminal.get` may prove `exited`; only the latter may report `live`; all other unproved states are `unverifiable`. A proved exit survives same-controller recovery, disconnect, and disposal. The client does not start a status query automatically.

`appliedGeometry` is null until an eligible view successfully finishes a baseline, applies a control/resize event, or commits a proved same-view retained replay. It records the establishing sequence, which can be earlier than `appliedSeq`. `appliedAuthority` is null until a control event is successfully applied. Its non-null `{holder: null}` form is a proved no-holder control fact, distinct from no applied fact. Neither field grants input permission; `inputReady` still follows the existing focus, target, phase, and observed/applied control conjunction. Received foreign control may revoke input while an older applied fact remains visible during parsing.

Initial attach, recovery, replacement, loss, and disposal clear the applied projections before external callbacks. A same-view replay can restore only a copied geometry from a proved retained renderer model, and never restores previous authority. The projections and their nested geometry/holder references are detached and frozen in each snapshot; a renderer cannot mutate the pending baseline descriptor's geometry into a later public fact.

Author validation uses the installed pinned Node 26.10.0 and pnpm 12.6.0. Commit A passed client TypeScript, Oxlint, Prettier, JavaScript syntax, pure client build, and four new execution cases. Commit B adds seven focused cases for applied facts, recovery, teardown, and observer reentry. The final scoped client run and exact outcomes are recorded in the frozen off-tree implementation report. These source checks do not replace independent source review, the formal twelve-group finite QA, or the registrar's isolated ES-only public consumer and suite registration.
