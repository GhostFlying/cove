## Meaningful environment smokes and negative acceptance

Register real Vitest projects `terminal-engine-probes` and `terminal-web-probes`, using Node as the test host. Their wrappers spawn compiled Node entries in child processes and require successful bounded results; browser behavior is measured in actual Playwright Chromium, not jsdom. Use one native/browser test worker and no parallel native stress. No actual 100-PTY or SSH run belongs to B0.

1. **Compiled exports and isolation.** From a clean output state, build and import both experimental exports with plain Node, and compile a small consumer against their emitted declarations. Explicitly reject their private `src`, `probes` implementation and `dist` subpaths. Check declared dependency graphs: engine Node output does not require DOM/browser xterm, browser assets cannot include Node/native modules, and no protocol/client placeholder or cross-package source alias exists. An isolated fixture that introduces a forbidden dependency/import must make the boundary test fail; merely scanning for one string is insufficient.
2. **Native and headless environment.** A compiled engine entry launches exactly one synthetic Node child via node-pty with an explicit temporary cwd, dimensions and argv. Wait for a readiness marker, send a fresh nonce and require a child-computed acknowledgement, resize and require the child's TTY size report, then request an explicit exit code and observe it. Feed bounded synthetic output through headless's parse callback, serialize to VT and apply to a fresh same-size model; compare the known line/cursor after completion. This demonstrates load, spawn/read/write/resize/exit and basic serializer plumbing. It proves no saved-state, partial-parser, reflow, query or full-profile equivalence.
3. **Real browser environment.** Serve only Vite's built fixture from a random numeric-loopback port; launch the pinned browser, construct/open xterm, write a synthetic marker through its callback, assert the public buffer/cursor and nonzero rendered geometry, focus the terminal and use Playwright keyboard events to obtain expected user input. Assert no browser console/page errors and no missing assets/external CDN requests. No PTY/network protocol is wired to that input. This proves an executable DOM/input environment; Q1 still must prove genuine-input provenance and suppression of automatic query replies during live parsing/replay.
4. **Owned-resource cleanup.** Both entries bound output, time and state, track their own child/browser/server identities, dispose models and handles in `finally`, close the ephemeral listener, remove task-owned temporary data and confirm child exit on success/failure. A nonce mismatch, unavailable binary, bad loader path, timeout or unexpected exit must be nonzero with bounded diagnostics. Never `pkill`, kill by stale PID alone, close user terminals or treat loss of contact as exit.

Independent tests must additionally exercise missing compiled JS/declarations, absent browser assets or managed executable, a failing native load, a wrong child nonce/exit, and timeout cleanup using isolated fixtures/injected launch paths. Do not corrupt the shared pnpm store or replace a system native binary to simulate failure. Removing a required suite, excluding its project, skipping a test or omitting one smoke must fail C1 discovery/execution accounting. A failed native/browser test is not accepted as an environment skip. A synthetic native-loader error tests propagation; it is not evidence of a real ABI mismatch reproduction.
