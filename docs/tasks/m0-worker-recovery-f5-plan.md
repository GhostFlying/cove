## Transaction boundary

RunSession's pump is the sole ordered authority for input. After it checks installed subscription, holder/epoch, input sequence, counter exhaustion and first-identity capacity, it invokes a synchronous admitted-input continuation. That continuation may reclaim only replay-ring ownership and then attempts the existing input retained reservation/native submission. No `await` occurs between the validation and reclaim/callback. Denied logical input never invokes reclaim. Attempted input sequence and identity remain consumed under the existing semantics once the ordered logical admission succeeds, even if subsequent resource/native admission rejects; there is no retry.

The public `execute` boundary must still reserve and copy mutable caller payload before its first await. A targeted original-workload preflight recorded 203,217 accounted bytes out of B=262,144, including two 65,536-byte tails and replay entries of 6,186 and 6,198 bytes. Its 58,927 ordinary free bytes suffice for the 20,000-byte command copy; the later `2*20,000+768` native reservation is where minimum reclamation is needed. Thus no new staging pool or budget partition is justified. For other states where the command copy cannot be reserved, return existing `BUSY` without replay mutation or native write. Preserve pending-command, ID and reply reservations, per-run ordering, and command cleanup on every denial. This boundary remains a conservative early resource rejection, not an authority decision; only the ordered pump can authorize replay mutation.

For a logically admitted input, reclaim until ordinary headroom covers the remaining native `2 * payloadBytes + 768` requirement; the command copy is already charged. Check capacity after every whole-ring eviction, stop immediately on sufficiency, and advance a deterministic rotating run cursor at each eviction. Pinned facts keep their lease; route sent-ledger/logical credit and endpoint physical bytes are never reclamation candidates. If eviction cannot restore enough headroom, preserve `BUSY`/rejected behavior without native write or leaked lease. Ring gaps must force baseline, not false replay.
