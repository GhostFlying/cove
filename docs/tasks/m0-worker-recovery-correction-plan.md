## Corrections and causal oracles

1. **F1, O/X classification.** Put `recover` in ordinary O admission in both endpoint and execution. Keep the synchronous old-token fence and marker-enqueued activation; do not use X as an ordering substitute. Endpoint and execution tests use B=1,C=4112: an unsettled O recover does not deny an X ACK/progress for another route, and an observed X response before its physical write callback parks at most one raw next X command until callback settlement. The same-ref state transition remains fenced.
2. **F2, replay discontinuity.** A selected interval `(cursor,current]` containing a retained resize with `requiresBaseline` is not a valid replay. Refuse it before pinning a selection and let the existing ordered baseline capture run. A cursor at/after that resize and an ordinary contiguous interval remain replay-eligible. A discontinuity already evicted naturally remains a sequence gap and cannot become a false replay.
3. **F3, turn cap.** Before enqueue, test `turnBytes + exactFrameCharge <= 256*1024`, retaining the 32-frame and round-robin bounds. If a legal next frame would cross the turn bound, schedule another turn rather than silently stalling. A two-route test records each actual service turn, asserts its exact sum and later progress of the deferred frame.
4. **F4, retained-byte ownership.** For replay/post-N clones, conservatively reserve payload bytes plus twice the `JSON.stringify(event)` code-unit count and fixed per-object/array overhead before cloning; this covers UTF-16 metadata, including full palette, and the retained array entry. For selected replay references, scan contiguity without an allocation, then lease a conservative per-reference array charge before materializing the selected pointer list; release with the slice. For each sent-ledger record, reserve a per-item lease before enqueue and retain/release it with ACK or route fence, independent of the source fact lease. For baseline transfer, compute chunk count without constructing views, lease a conservative per-frame table plus metadata bound before materializing chunks/events/frames, then retain that lease until final ACK or fence. Raw detached baseline VT/tail remains in its separate exact public-capture lease. Denial fails the route before retained allocation or frame enqueue. Tiny-worker-budget and maximum-metadata/count tests must observe refusal, peak accounting, ACK/fence release, and final zero owned bytes.

The preserved W1 256 KiB pressure oracle exposed a resource priority issue during implementation: the first native-input reserve can fail if best-effort replay history occupies its last few KiB. Post-N may pin an already charged immutable replay fact and separately charge only its bounded reference; if replay could not retain the fact, post-N must reserve a full independent clone. Appearance retention also adds 64 bytes per palette entry on top of the UTF-16-safe serialized metadata bound; the sent ledger reserves 256 bytes per item before enqueue. Baseline frame-table charge uses the exact start/end metadata lengths and the longest possible chunk ordinal, twice their JSON code-unit lengths plus 512 bytes per wrapper/view/slot, before views exist. Before an admitted input reaches the native adapter, evict oldest replay-cache entries only until command charge plus the existing `pty-input.ts` reservation `2*payloadBytes+768` fit. A pinned entry keeps its underlying lease until its route releases it, and if eviction cannot free enough bytes the original BUSY behavior remains. This retains the exact tail/input lengths, budget, second-input rejection and cleanup assertions; it is not a higher cap or a weaker workload.

These are conservative charges for bounded retained objects, not a claim to measure the JS heap exactly. Wire frame bytes are separately accounted by the endpoint and logical credit; no lease is released by mere logical ACK if physical transport still owns a frame.
