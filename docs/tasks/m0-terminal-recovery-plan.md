## Small experiment and oracle

Use a handful of domain files under `probes/`: `recovery-boundaries.ts` (explicit runner, inert import), `recovery-checkpoint.ts` (candidate), `recovery-observation.ts` (oracle), `xterm-recovery-state.ts` (one guarded private surface if necessary), and authored `*.test.mjs`. Fixture files under `tests/fixtures/terminal/engine/` contain synthetic bytes, cuts, dimensions, ordered write/resize operations and hand-authored expectations. Split further only for actual responsibility/size; no registry or plugin system.

For every fixture and checkpoint cut:

1. Feed a fresh uninterrupted reference the exact byte prefix, awaiting write callbacks. Track byte offset separately from event `seq`; do not turn transport reads into parsed acknowledgements. Candidate source consumes the identical operations, including resize. The runner may use byte-sized writes to expose exact boundaries, then repeat with deterministic coalesced/chunked writes; this is a feasibility experiment, not a production throughput algorithm.
2. Capture public observations and the candidate recovery bytes at a settled boundary. Generate the baseline twice and prove source state/replies do not change. Start a fresh restore model with the same options/Unicode policy/dimensions and parse the bounded baseline plus retained tail. Do not clone source private objects into the restore model.
3. Compare before the suffix, then feed the identical suffix/resize sequence to reference and restored models and compare at each meaningful barrier. Dispose and recreate the receiver to rule out retained-state shortcuts. Query output from the restored model is an observation sink, never a second PTY reply source.
4. Oracle compares retained normal and alternate cells (characters, width, styles/colors and wrapped flags), active buffer, current cursor, exposed modes, retained history coverage, exact query replies and ordered externally visible side effects. Use read-only guarded internal observations only where public state is absent; do not use the candidate serializer as its own oracle. Assert known sentinel outcomes in addition to differential equality, and fail on a missing observation.
5. Exercise hidden state behaviorally: later DECRC/ANSI restore then print and query; leave alternate then print; scroll at margins; shift charset; use custom tab stops; print at pending wrap; continue combining/REP; resize both buffers. Equality must concern the source's retained state, not history already evicted. Snapshot equality without these continuations does not pass.

Keep all parser/grid/history annotations local to the experiment. Wire payload remains VT bytes plus proposed renderer-neutral coverage/boundary metadata; private object graphs, cell arrays and parser enum/state dumps cannot enter protocol schemas, exports or the recovery payload.

### Checkpoint plus tail candidate

Maintain one recoverable serialized checkpoint at byte offset K and a capped byte tail covering exactly `(K, N]`, where N is the requested parsed prefix boundary. K must have no incomplete UTF-8 code point or unfinished escape/control string; the checkpoint must also pass the hidden-state continuation oracle. Choose K before the unfinished sequence and its C0 side effects. Restoring checkpoint K then tail once must produce state N; taking a snapshot at N then appending that same tail is forbidden.

The probe first attempts public APIs plus explicit byte-boundary tracking. Validate the tracker against actual pinned decoder/parser observations, including abort transitions; public end-of-sequence handlers alone cannot certify arbitrary in-flight state. A bounded private reader may inspect `_core._inputHandler._parser.currentState`, `_utf8Decoder.interim` and settled write completion. Do not copy OSC/DCS handler state or serialize their internals. Record how a checkpoint is refreshed after completed sequences and before output arrives in coalesced chunks. Dropping arbitrary bytes to find ESC or resetting the live model is not recovery.

Supplement serialize output with VT restoration experiments for both buffers' saved cursor/SGR/charset, current pen/charset, margins, origin and other modes, tab stops and current wrap-pending. Try full-region positioning, reconstruct saved pen/charset before DECSC, rebuild retained content, restore current state and leave pending tail last; prove ordering does not clobber saved registers, hidden normal state or pending wrap. Treat this as a hypothesis, not a claimed algorithm. Never patch private destination cells/registers to make an otherwise nonrepresentable VT baseline appear valid.

If public APIs cannot read necessary state, confine read-only access to `xterm-recovery-state.ts`: normal/alternate buffers via `_core._bufferService.buffers`, their `savedX/savedY/savedCurAttrData/savedCharset/scrollTop/scrollBottom/tabs`, current `_inputHandler._curAttrData`, `_charsetService` designation/shift state and parser/decoder observations above. Verify exact runtime shape against the mapped sources; access is a candidate, not permission to assume every property exists. Check exact installed versions plus relevant package hashes, with explicit failure on absent/mismatched fields. Upgrade probes rerun all mandatory continuations and missing-field/wrong-version counterexamples. No default zeros or fallback claiming complete recovery.

If supplemental VT cannot represent a required state, preserve the smallest counterexample and propose a bounded maintained engine/addon patch with exact source surface, resulting VT/metadata semantics, version/hash guard, downstream Q1 impact and upgrade fixtures. Coordinate patch/lock ownership before editing. Actual behavior changes, architecture changes or narrowing the accepted recovery contract go through the coordinator to the user before P1b; no required case is relabeled optional.

### Bounds and synthetic transport

Start with explicit experimental limits: 120×40 maximum grid, 1000 retained history lines (plus a forced 3-line budget), 64 KiB raw tail, 8 MiB checkpoint VT, 30-second per-case watchdog and fixed fixture count. These are tunable probe limits, not the final production profile. Check tails at cap−1/cap/cap+1 and stream a much longer unterminated OSC/DCS incrementally without retaining the source stream or all observations. Bound fixture generation, parser-hook storage, diagnostics and baseline assembly too; account for live model, one checkpoint, tail, temporary old/new checkpoint overlap, encoded copies and receiver/reference models separately. Record peak retained bytes and serialization duration; RSS alone is not a bound proof.

For a pathological over-limit unclosed sequence, continue authoritative live parsing and query behavior, release invalid recovery retention, return explicit bounded recovery-unavailable and resume only after a newly proved checkpoint. Never reset the source, inject control bytes, fake ground, drop live output, or restart anything. This exception covers pathological overflow only; every required bounded valid fixture below must restore. A valid fixture exceeding an initial engineering limit requires revising that limit/strategy, not weakening acceptance.

Use built `@cove/protocol/provisional/terminal` and `/provisional/pipe` exports to round-trip small output/baseline fixtures, including partial byte frames and interleaved synthetic request IDs. Perform the existing fatal UTF-8/JSON/metadata validation composition and compare full worker/run/request/baseline identity. Bound local assembly and verify chunk count/index/total. Reject deliberately wrong correlation and missing/duplicate chunks before installation. `baselineId` links local annotations; P1a does not carry or freeze them. This proves synthetic byte preservation/correlation only, not worker IPC, subscriptions or runtime ordering.
