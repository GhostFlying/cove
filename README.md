# Cove

A focused workspace for tasks and coding agents, across desktop, mobile, and remote hosts.

## Status

Early design stage. No application has been implemented yet.

## Intended scope

- Task-centered worktree and folder workspace management.
- Persistent terminal sessions with remote access and reconnection.
- Lightweight chat support for a small set of agents.
- A mobile client for the same core workflows.

Integration with Shepherd is being explored. Architecture, technology choices,
and the integration contract are still open for discussion.
